Template▼
A template saves the roster: names, mic assignments, sides, camera mapping, shot types, cam ids and target shares. Loading onto a different track count reconciles what it can and flags the rest. Settings are normally left alone, so Set the look and Advanced persist across templates, projects and restarts while you dial them in. Tick the box above to pin the current settings to a template as well, and loading it will then apply them.
Range▼
Everything outside the range is left untouched. Use this when camera assignments change partway through: set in/out, remap, run, then move to the next stretch.
Speakers▼
One row per audio track that has clips. Side drives opposing-side reaction weighting.
Cameras▼
Click a name to toggle whether that person is visible on this camera. Cam id is which physical body the footage came off, detected from the footage folder. Tracks sharing an id never cut against each other, because two crops of one sensor read as a jump cut. It is about the camera, not the side: two separate bodies covering the same side get different ids so they can still cut together. Target % is optional, and auto is fine.

Speaking balance▼
Talk is how much of the range this person is talking. Silence and people talking over each other mean it lands near 100% rather than exactly on it. Seen when talking is how much of their own speaking time a camera was actually on them, which is the number that finds someone being missed. Under 80% is amber, under 60% is red. On screen overall is a different measure and deliberately does not add up to 100%: a group shot puts four people on screen at once, so all four are counted for it.
